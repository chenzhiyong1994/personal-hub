## 个人项目证据

项目事实来自作者拥有或有权审查的项目仓库、README、测试、素材和本地运行结果。公开页面采用保守状态描述：本地跑通不等于生产接入，自动化测试不等于真实用户采用，候选版本不等于正式发布。

1. **北页 / BeiyeMD**：Windows 与 macOS v1.1.0；本地 Markdown 工作区、多文档编辑、外部变更处理与 GitHub Releases。
2. **AI Business Twin**：本地 v1.0 实验；包含事件历史、L1/L2/L3 策略、审批、审计、全局暂停和备份。只声明夹具流程已验证，不声明真实渠道已接通。
3. **Stack Trail**：本地 v0.14 自测实验；包含证据门禁、验证实验、恢复/迁移和作品集输出，不包含外部采用主张。
4. **胶囊办公室**：Electron / React / xterm 原型；包含真实 PTY 会话、空间化 Agent 状态，以及真实/估算/不可用指标的显式区分。
5. **悄醒 / HushWake**：Android v0.3.2 beta；覆盖 API 31–36、精确闹钟、前台服务、路由核验和失败关闭的音频安全策略；实体耳机零泄漏验收仍待完成。
6. **别骂了**：AI 结构化评审小程序 v1.0；包含四种角色、共享报告协议、来源证据、修改动作、验收标准、临时存储隐私和 evals。
7. **心镜拾光**：v1.1 候选版本；包含 78 张牌、CloudBase AI、默认离线、结构化安全/事实检查、本地历史和分享海报。
8. **生者未明**：v0.4 可玩微信社交推理游戏；包含 NPC 状态与证词、不可改写事实的可选 AI，以及 40 局种子自动化测试。

`content-os`、`AIGC`、`career-os`、`novelist` 和 `product-manager` 作为可重复工作系统呈现，而不是独立商业产品。`topic-scout` 与 `fresh-thing` 保留在项目图谱中，表示更早或已演化的实验路径。

这些材料不能推导出商业 AI 任职经历、外部采用规模或真实渠道生产状态。
